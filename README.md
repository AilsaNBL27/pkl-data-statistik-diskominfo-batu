Rekap, Verifikasi, dan Migrasi Data Statistik Daerah
Dinas Komunikasi dan Informatika Kota Batu — Bagian Data dan Statistik

---
1. Latar Belakang
Sebagai bagian dari implementasi program Satu Data Indonesia (SDI) di tingkat daerah, Dinas Komunikasi dan Informatika Kota Batu memerlukan proses pengelolaan data statistik yang akurat, terverifikasi, dan mudah diakses melalui portal data resmi. Selama periode PKL, saya terlibat langsung dalam proses pengumpulan, pemilahan, verifikasi lintas sumber, visualisasi, hingga migrasi data statistik daerah ke sistem portal data yang digunakan Diskominfo Kota Batu.

2. Tujuan
Melakukan pemilahan dan pengelompokan data statistik daerah (data badan, bagian, dan kecamatan) agar sesuai standar input portal data.
Memverifikasi keakuratan data statistik daerah melalui perbandingan dengan sumber resmi BPS (Indah BPS dan ROMANTIK) serta portal statistik lokal (Sataku Kota Batu).
Membuat visualisasi sederhana (grafik) dari data yang telah direkap untuk mendukung pelaporan.
Melakukan migrasi data dari sistem lama ke portal data versi baru milik Diskominfo Kota Batu.

3. Tools yang Digunakan
Microsoft Excel (pemilahan data, rekap, dan pembuatan grafik)
Portal Data Diskominfo Kota Batu (sistem lama dan versi baru)
Website Indah BPS (https://indah.bps.go.id/)
Website ROMANTIK BPS (https://romantik.web.bps.go.id/)
Website Sataku Kota Batu (https://sataku.batukota.go.id/)
Google Form (untuk instrumen survei pendukung)

4. Alur Kerja
```
1. Pemilahan Data Awal
   Data badan, bagian, dan kecamatan dipilah dan dirapikan di Excel
              |
2. Input ke Portal Data (Sistem Lama)
   Data yang sudah dipilah diunggah ke portaldata Diskominfo
              |
3. Rekap & Verifikasi Data Statistik
   Metadata direkap dari Indah BPS (2021-2024), lalu diverifikasi ulang
   melalui ROMANTIK dan Sataku Kota Batu
              |
4. Visualisasi Data
   Rekapan data statistik divisualisasikan dalam bentuk grafik di Excel
              |
5. Pengelompokan Data Berdasarkan OPD
   Data dari lampiran SK penyebarluasan e-Walidata dipisah per OPD
              |
6. Migrasi ke Portal Data Baru
   Seluruh data (termasuk data desa Sidomulyo dan Pesanggrahan)
   diunggah ulang ke sistem portal data versi baru
```
5. Rincian Kegiatan per Tahap
Tahap 1 — Pemilahan & Input Data Dasar 
Memilah data badan, bagian, dan kecamatan menggunakan Excel, kemudian mengunggah seluruh hasil pemilahan ke portal data Diskominfo Kota Batu.
Tahap 2 — Rekap & Verifikasi Data Statistik 
Merekap metadata dari website Indah BPS untuk rentang tahun 2021–2024, membuat grafik dari hasil rekapan, lalu memverifikasi ulang data melalui website ROMANTIK dan Sataku Kota Batu untuk memastikan akurasi sebelum digunakan sebagai bahan laporan/jurnal.
Tahap 3 — Pengelompokan Data Berdasarkan OPD 
Memisahkan dan mengelompokkan data dari lampiran SK penyebarluasan e-Walidata berdasarkan Organisasi Perangkat Daerah (OPD) masing-masing.
Tahap 4 — Migrasi ke Portal Data Baru 
Mengunggah ulang seluruh data bagian dan kecamatan (termasuk data desa Sidomulyo dan Pesanggrahan) ke sistem portal data versi baru milik Diskominfo Kota Batu.

5. Hasil
Data statistik daerah (badan, bagian, kecamatan) berhasil dipilah, diverifikasi, dan terunggah di portal data Diskominfo Kota Batu, baik di sistem lama maupun sistem baru.
Rekapan metadata BPS 2021–2024 tervisualisasikan dalam bentuk grafik sebagai bahan pendukung laporan/jurnal internal.
Data lampiran SK e-Walidata terkelompok rapi berdasarkan OPD, memudahkan proses audit dan pelaporan.

6. Catatan
Data asli milik instansi (Diskominfo Kota Batu) bersifat internal dan tidak dipublikasikan di repository ini karena alasan kerahasiaan. File pada folder `sample-data/` merupakan data dummy yang dibuat untuk menggambarkan struktur dan format data yang sebenarnya diolah, tanpa memuat data riil milik instansi.
Selain project utama ini, selama PKL saya juga terlibat dalam penyusunan draf jurnal ilmiah bertema SPBE dan SDI bersama pembimbing lapangan. Jurnal tersebut belum selesai dibuat hingga akhir masa PKL, sehingga dilampirkan sebagai dokumen pendukung, bukan sebagai deliverable utama.
